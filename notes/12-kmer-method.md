# 无比对 k-mer 定点验证方法（自研，Innovation 素材）

日期：2026-08-26

## 问题

两件事都需要回到原始 reads，但都不需要全基因组比对：
1. **BUB1B 双变异的 read 级验证**（Track 1 严谨性）
2. **PGx 位点的覆盖度验证**（Track 1 次要发现——variant-only VCF 无法区分"真野生型"与"没测到"）

全基因组比对代价：10 核约 12-30 小时 + 数十 GB BAM。而我们只关心 9 个位点。

## 方法

对每个位点，从 GRCh38 取变异两侧各 30bp，构造 ref 与 alt 两条 61bp 探针序列，
取其中**所有跨越变异位点**的 31-mer（各 31 条）及其反向互补（共 62 条/集合）。
单遍流式扫描 FASTQ，每条 read 对每个 (位点,等位) 至多计一次，累加得 ref/alt 支持数。

优点：一次扫描同时回答两个问题；无需 BAM；磁盘占用近零；可断点续跑（按文件记账）。

## 唯一性 QC（这是方法能否成立的前提，也是本方法最有价值的部分）

k-mer 计数的效力前提是探针在基因组中唯一——否则假基因/片段重复的 reads 会被误计。
我们对此提供**直接证据**而非假设：单遍扫描 GRCh38 primary assembly（3,088,286,401 bp），
统计每条探针 k-mer 的出现次数。

结果（`05_probe_uniqueness_qc.py`）：

- **所有 alt k-mer 在参考基因组中出现 0 次**（9/9 位点，62/62 条）——正向验证：alt 等位基因确实不在参考中，alt 信号不会来自参考序列本身
- ref k-mer 期望：单链扫描下 31 条正向命中 1 次、31 条反向互补命中 0 次。8/9 位点符合
- **TPMT\*3C (rs1142345) 例外：7 条 ref k-mer 命中 2 次** → 定位（`06_locate_dup_kmers.py`）显示重复命中聚集于 **chr3:42,145,646-42,146,371 = TPMTP2（thiopurine S-methyltransferase 加工假基因 2）**

## TPMTP2 混杂的临床影响分析（报告要点）

- 影响方向：来自 TPMTP2 的 reads 会被误计为 TPMT\*3C 的 **ref 支持**，**高估**该位点覆盖度
- 不影响的方面：alt k-mer 全基因组唯一（含假基因区）→ **若检出 alt，是真信号；若未检出 alt，阴性判断仍成立**
- 因此结论方向：即使存在混杂，"未携带 \*3C"的阴性判读仍安全；但"覆盖度充分"这一措辞对该位点须打折
- **修复**：`kmer_probes_masked.json` 剔除 7 条非唯一 k-mer（TPMT\*3C ref 集 62→55），其余位点不受影响。扫描默认使用净化探针集

## 方法学论述价值

1. TPMT 假基因干扰是**已知的临床遗传学难题**，我们的管线不是"碰巧避开"，而是**主动检测并量化**了它——这正是可推广到其他病例的方法学产出
2. "alt k-mer 在参考中 0 次命中"是一个廉价但有力的自检，任何 k-mer 分型管线都应做
3. 对比：标准 PGx 工具（PharmCAT）对缺失位点默认判 no-call，其 `--absent-to-ref` 开关官方标注 DANGEROUS；我们用 reads 直接回答覆盖度问题，而非依赖开关假设

## 坐标教训（记录以免重犯）

首轮 PGx 位点坐标为手写，其中 **5/7 是错的**（rs67376798、rs75017182、rs115232898、rs1142345、rs1800460）。
经 Ensembl REST /variation 重新解析后修正。
- 幸运的是结论未变：用正确坐标重查，7 个位点在 VCF 中仍全部无记录
- 防御措施已内置：`build()` 断言参考碱基必须与 FASTA 一致，坐标错误直接失败而非静默出错（该断言正是捕获此错的机制）
- 教训写进 methods：任何硬编码基因组坐标都必须有参考序列校验
